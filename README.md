## 👋 About Me

> 🇬🇧 **English**

I'm a game and web developer based in **Istanbul, Türkiye**. I enjoy turning ideas into playable experiences and building clean, fast and modern web interfaces. I like working across the whole stack — from gameplay systems and game logic to front-end design and data layers.

- 🎮 Building games with **Unity** and **C#**
- 🌐 Creating web applications with **HTML, CSS and JavaScript**
- 🗄️ Working with relational and **vector databases**
- 🤖 Interested in AI-powered applications and semantic search
- 🌱 Always learning and experimenting with new technologies

> 🇹🇷 **Türkçe**

**İstanbul**'da yaşayan bir oyun ve web geliştiricisiyim. Fikirleri oynanabilir deneyimlere dönüştürmeyi, sade, hızlı ve modern web arayüzleri tasarlamayı seviyorum. Oyun mekaniklerinden ve oyun mantığından ön yüz tasarımına ve veri katmanına kadar projenin her aşamasında çalışmaktan keyif alıyorum.

- 🎮 **Unity** ve **C#** ile oyun geliştiriyorum
- 🌐 **HTML, CSS ve JavaScript** ile web uygulamaları yapıyorum
- 🗄️ İlişkisel ve **vektör veritabanları** ile çalışıyorum
- 🤖 Yapay zekâ destekli uygulamalar ve anlamsal arama ilgimi çekiyor
- 🌱 Sürekli yeni teknolojiler öğreniyor ve deniyorum
